HTML Introduction

HTML is the standard markup language for creating Web pages. HTML describes the structure of a Web page and consists of a series of elements.

Tip: HTML elements tell the browser how to display the content.

A Simple HTML Document

Example 
<!DOCTYPE html>
<html>
<head>
 <title>Page Title</title>
</head>
<body>
 <h1>My First Heading</h1>
 <p>My first paragraph.</p>
</body>
</html>

Example Explained

  • The <!DOCTYPE html> declaration defines that this document is an HTML5 document
  • The <html> element is the root element of an HTML page
  • The <head> element contains meta information about the HTML page
  • The <title> element specifies a title for the HTML page
  • The <body> element defines the document's body

CSS Introduction

CSS is the language we use to style an HTML document. CSS describes how HTML elements should be displayed.

Example 
body {
 background-color: #0f172a;
 color: #e2e8f0;
 font-family: Inter, sans-serif;
}

h1 {
 color: #38bdf8;
 font-size: 2.5rem;
}

JavaScript Introduction

JavaScript is the programming language of the Web. It can update and change both HTML and CSS, and can calculate, manipulate and validate data.
